# Food Dash 🍔

Food Dash is a responsive food delivery website designed to provide a simple and engaging online food-ordering experience. The website features a modern landing page with a navigation bar, hero section, popular Indian dishes, regional food categories, regular menu items, special offers, and service highlights such as fast, fresh, and free delivery.

It also includes dedicated **Login** and **Signup** pages for user authentication and a structured footer containing navigation, information, and contact details.

### Features

* 🏠 Responsive home/landing page
* 🍽️ Indian and regional food menu
* 🔎 Search interface
* 🛒 Food ordering interface
* 🎁 Special offers section
* 🚚 Fast, fresh, and free delivery highlights
* 🔐 Login and Signup pages
* 📱 Responsive design using Bootstrap
* 🎨 Custom styling with CSS
* ⭐ Food ratings and customer reviews
* 📞 Contact and social media section

### Technologies Used

* HTML5
* CSS3
* Bootstrap 5
* Bootstrap Icons
* JavaScript
* Google Fonts

### Project Structure

The project is organized into separate HTML pages, CSS styling, JavaScript functionality, and image assets, making it easy to maintain and expand.

Food Dash was created as a frontend web development project to practice responsive layouts, Bootstrap components, navigation, UI design, and multi-page website development.
